# DefaultSearch

轻量 Telegram TRON/USDT 工具机器人。

联系方式：@XiaoShuoTech

- 单 OWNER 使用
- TRON 地址查询
- USDT/TRX 余额
- USDT 转入/转出/全部交易分页
- 多签检测
- U 价换算
- 地址进出账监控通知
- SQLite 本地数据库
- 无 Web 面板、无域名、无开放端口
- 链上数据只使用 TronGrid 官方 API

需要 Node.js 24 或更高版本，不需要 `npm install`。

## 配置

```bash
cp .env.example .env
```

填写：

```env
BOT_TOKEN=
OWNER_ID=
```

`TRON_GRID_API_KEY` 可不填。留空时地址查询和监控都走公共 TronGrid 接口。`TRON_API_RETRIES` 控制 TronGrid 请求失败后的重试次数，默认 3 次。

## 启动

```bash
npm start
```

## 操作

```text
/start                       打开按钮主菜单
菜单                         打开按钮主菜单
主菜单按钮                    查U价 / 地址查询 / 人民币换U / U换人民币 / 监控管理 / 运行状态 / 系统日志 / 清空数据
监控管理按钮                  列表 / 添加 / 删除 / 启用 / 暂停 / 手动检查 / 系统日志
```

日常操作不需要输入斜杠命令。地址查询、添加监控、删除监控、启用监控、暂停监控、手动检查、金额换算都可以先点按钮，再按提示发送内容。监控列表会显示 `#编号`，地址查询、删除、启用、暂停、手动检查支持发送 `#编号`、唯一备注或完整地址。发送“取消”可退出当前输入。

需要回复内容的操作默认保留 5 分钟，可通过 `PENDING_ACTION_TIMEOUT_SECONDS` 调整。成功、取消或超时后，机器人会清除操作状态并删除原来的输入提示；输入错误时操作继续有效，可以直接重新发送。

无需先点菜单，也可以发送 `快捷 #1`、`快捷 备注` 或 `快捷 TRON地址` 直接查询。添加地址时备注不能重复，避免按备注查找时选错地址。

地址查询结果会显示多签状态，并提供“多签详情”按钮查看 Owner/Active 权限明细。

运行状态会显示运行时长、内存、数据库大小、监控参数、最近通知、最近查询、最近错误。系统日志会显示运行事件、最近监控通知、最近查询记录。

“清空数据”会二次确认后删除监控地址、交易通知记录、查询记录、系统日志和临时状态，但保留 Telegram 轮询位置，避免旧消息重新处理。

## 说明

第一次添加监控地址时，机器人只记录当前最新交易，不推送历史交易；之后出现新转入/转出才会通知。通知包含当前 USDT/TRX 余额、本次交易、上一笔 USDT 交易和 Tronscan 详情链接，链接预览默认关闭。

新交易会先写入 SQLite 待发送队列，只有 Telegram 返回发送成功后才标记为已通知。发送失败会保留待发送状态并在后续监控轮询中重试，服务重启也不会丢失队列。

监控查询会按页追踪到上次成功检查的位置，`MONITOR_TX_LIMIT` 表示每页数量，不是单轮最多处理数量；同一轮发现多笔交易时按时间从旧到新推送。

链上余额、USDT 交易、多签检测只走 TronGrid 官方 API。没有配置 `TRON_GRID_API_KEY` 时，地址查询和监控查询都会使用公共接口；公共接口可能限速，监控地址多时建议填写自己的 TronGrid API Key。

Telegram 请求固定使用 DNS 首选的 IPv4，每次消息轮询使用独立连接。网络失败日志会记录底层错误码，便于区分超时、连接重置和 DNS 故障。
当前服务器线路会主动重置 Telegram 长连接，因此默认改为每 2 秒一次的短轮询：`POLL_TIMEOUT_SECONDS=0`、`POLL_INTERVAL_MS=2000`。平均消息响应约 1 秒，同时避免维持容易被重置的长连接。
机器人启动时会依次完成命令清理和启动通知，再进入消息轮询，避免启动瞬间并发多个 Telegram 请求。

概览里的收入、支出、交易笔数来自 TronGrid 分页扫描，默认扫描最近 `HISTORY_SCAN_LIMIT=1000` 笔 USDT 交易。老地址如果历史交易非常多，可以调高这个值，但 API 调用次数也会增加。

U 价使用 OKX C2C 公开报价。点击“查U价”会显示“购买U/出售U”和“全部/支付宝/微信/银行卡”的按钮，点击后显示对应前 20 个商户，只显示商户名和价格；如果 OKX 临时不可用，换算会使用 `.env` 里的 `FALLBACK_USDT_CNY_PRICE`。
